## Why this matters

Four components (~1,000 lines) have zero importers — they are superseded UI generations (`SmartInput` replaced `TextInput`; `InlineEventEditor`/`BatchEventList` replaced `EventEditor`/`EventConfirmation`/`ExportOptions`) that still get type-checked, read by every future agent session, and matched by searches. `@anthropic-ai/sdk` sits in production dependencies with zero imports anywhere (all LLM traffic is raw fetch to OpenRouter). `dotenv` is a production dependency but is only imported by `playwright.config.ts` (a dev-time file). And `run.sh` — the README's "Quick Start" — installs and uses **pnpm** in a repo standardized on bun (commit 29b2676 "standardize on bun as package manager"), silently `npm install -g`-ing onto the machine of anyone who follows the README.
